# 资料属性

本文件是为 TJU NetPilot RAG 测试整理的北洋维基社区资料摘要，不是天津大学官方配置手册。无线认证参数和证书要求可能更新，连接前应在学校信息与网络中心或受访单位的官方说明中复核。

# 服务用途

eduroam 是面向教育和科研机构的无线网络漫游认证服务。资料称天津大学师生在支持 eduroam 的外访单位可以使用天津大学身份进行认证，通常不需要在每个外访单位单独开通账号。

# 登录标识

资料给出的用户名形式为“学工号加天津大学域名”，即 `学工号@tju.edu.cn`。密码属于个人敏感信息，只应在可信的系统无线认证界面中输入，不应发送给 NetPilot。证书、EAP 方法等详细参数应以学校最新官方配置说明为准。

# 排障建议

无法连接时，先确认所在位置确实提供名为 `eduroam` 的热点，再检查用户名是否包含完整域名。若系统提示证书、身份或认证方法错误，不应忽略证书警告，应停止连接并向学校网络支持渠道索取最新配置。
