# 资料属性

本文件是为 TJU NetPilot RAG 测试整理的社区资料摘要，来源是北洋维基，不是天津大学官方文件。原词条最后编辑于 2020 年，服务入口、资费和操作步骤可能已经变化，实际使用前应以天津大学信息与网络中心当前通知为准。

# 校园网接入

词条介绍的接入方式包括宿舍或教学楼有线网络，以及无线热点 `tjuwlan`；图书馆场景还提到 `tjuwlan-lib`。无线接入通常需要先连接热点，再使用浏览器打开非 HTTPS 页面触发认证页面。如果没有自动跳转，可以尝试访问校园网自服务页面 `http://g.tju.edu.cn/`。

# 常见登录问题

如果无线认证页面提示链接错误或无法跳转，不应继续使用以前收藏的旧认证页面。建议断开后重新连接 `tjuwlan`，打开非 HTTPS 页面触发新的认证流程。macOS 或 iOS 无法弹出认证页时，也可从校园网自服务入口重新进入。

# 支持渠道

词条列出的信息与网络中心服务电话为 `022-27404455`，并给出了信息与网络中心网站 `http://nc.tju.edu.cn`。这些联系方式同样可能变化，使用前应在学校官方站点复核。
