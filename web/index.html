      1. 下载诊断工具

      这个工具只读取与你当前网络故障有关的基础网络状态，不修改设置，也不会自动上传。

      会检查活动网络接口基本状态、默认网关、DNS 配置和少量固定 DNS/TCP 测试。不采集 Wi-Fi 密码、浏览历史、Cookie/Token、MAC 地址、SSID 或设备序列号。

      2. 在 Windows 本机运行
      
        
      先解压下载的文件包，将里面两个文件放在同一文件夹，查看脚本后双击 run_client_diagnostic_windows.cmd。请使用发生问题的这台 Windows 电脑，普通用户运行即可。
      
        
      完成后，同一文件夹会生成 netpilot-client-diagnostic.json。工具只生成本地文件，由你决定是否提交。
      
        
      如果组织策略阻止脚本运行，可以跳过检查并继续受限排查。请勿关闭或降低安全策略。
